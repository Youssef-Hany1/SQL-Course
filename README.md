# 📊 SQL Full Course – From Zero to Hero

This repository contains my code, notes, and projects completed while taking the [SQL Full Course for Beginners (30 Hours)](https://www.youtube.com/watch?v=SSKVgrwhzus) by **Data with Baraa**. 

The course covers the full spectrum of SQL, starting from absolute basics and advancing to complex data engineering and data analytics concepts used in enterprise environments.

## 🚀 Course Overview
This repository tracks my journey in mastering SQL, including setting up the database environment (SQL Server Express & SSMS), writing optimized queries, and building real-world data projects.

### 🧠 Key Topics Covered:
*   **Database Fundamentals:** RDBMS concepts, tables, schemas, and data types.
*   **DQL (Data Query Language):** `SELECT`, `FROM`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `DISTINCT`, and `TOP`.
*   **DDL (Data Definition Language):** `CREATE`, `ALTER`, and `DROP` tables.
*   **DML (Data Manipulation Language):** `INSERT`, `UPDATE`, and `DELETE`.
*   **SQL Operators:** Comparison, Logical (`AND`, `OR`, `NOT`), Range (`BETWEEN`), Membership (`IN`), and Search (`LIKE`).
*   **SQL Joins:** `INNER`, `LEFT`, `RIGHT`, `FULL`, `CROSS`, and Advanced Anti-Joins.
*   **Set Operators:** `UNION`, `UNION ALL`, `EXCEPT`, and `INTERSECT`.
*   **SQL Functions:** 
    *   **Single-Row:** String, Numeric, Date/Time, NULL handling (`COALESCE`, `ISNULL`), and `CASE WHEN` statements.
    *   **Multi-Row (Window Functions):** Aggregates, Ranking (`ROW_NUMBER`, `RANK`, `DENSE_RANK`), and Analytical functions (`LEAD`, `LAG`).
*   **Advanced Techniques:** Subqueries, Common Table Expressions (CTEs), Views, Temporary Tables, Stored Procedures, and Triggers.
*   **Performance Optimization:** Indexing (Clustered, Non-Clustered, Columnstore), analyzing Execution Plans, and SQL Hints.

## 🛠️ Real-World Projects
As part of this course, I implemented three hands-on projects mimicking real industry tasks:
1.  **Data Warehousing (ETL):** Building a data architecture (Bronze, Silver, Gold layers) and executing ETL processes.
2.  **Exploratory Data Analysis (EDA):** Profiling data, discovering key metrics, and conducting magnitude/ranking analysis.
3.  **Advanced Data Analytics:** Calculating moving averages, running totals, customer retention, and year-over-year (YoY) performance tracking using complex Window Functions.

## 💻 Tech Stack

*   **IDE:** SQL Server Management Studio (SSMS)
*   **Language:** SQL
